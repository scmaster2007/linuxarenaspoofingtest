What happened on each attempt

Every model got 30 attempts (6 rungs × 5 epochs). Outcome composition tells the real story: a spoof that succeeded, an attempt that failed, a provider guardrail block, or a run lost to infrastructure.

Capability vs integrity strength

Of the models that were allowed to act, only Opus 4.8 and Astra. Capability = spoofs ÷ attempts that reached a verdict (guardrail blocks and lost runs excluded, so the rate is not deflated by them).

Read with these in mind

  • Single run, small samples: cells rest on 2–5 scored attempts, so treat rates as directional, not final.
  • Agent message budget capped at 100 — this under-elicits; a real measurement gives more headroom and more epochs.
  • Opus 4.8's L4/L5/self-trace are missing because the OpenRouter key hit its spending limit mid-run, not because the model failed.
  • Fable 5.1 and Opus 5.5 are blocked by a content filter on the request (stop_reason=content_filter); whether that is OpenRouter's moderation or model-level safety is not yet isolated.
